How to use

  1. ✨ Create Routine walks you through everything in 5 steps: periods → classes → teachers → who teaches what → generate. You type everything in the app; no Excel upload is needed.
  2. Tap 🔒 Admin and enter the PIN (first time: 1234). Change it in Backup & Export.
  3. Install: on Android/laptop Chrome tap 📲 Install (or browser menu → Install app / Add to Home screen). On iPhone: Safari → Share → Add to Home Screen.
  4. Setup → Days & Periods: Monday–Friday, Morning shift 6 periods with one break, Noon shift with two breaks. Use ⏱️ Auto timing to change start time, period length or break length – all timings update by themselves.
  5. Setup → Subjects, Teachers, Classes: replace the sample names with your real ones. Set each class's shift and class teacher.
  6. Setup → Allocation: for every class, which teacher teaches which subject and how many periods a week. The total should not exceed the class's weekly periods.
  7. Teachers who are not available in some periods: Setup → Teachers → ⛔ Slots.
  8. Auto Generate builds the routine with no teacher clash. Then adjust by hand in Class Time Table: tap a period to change it or ⇄ swap two periods. Hand changes are locked 🔒, so you can run Auto Generate again and it fills the rest around them.
  9. Devotion / Fixed periods: Setup → ⭐ Devotion / Fixed → “Add Devotion (Monday, Period 1)”. Choose days, period, shift, classes and who takes it (no teacher, class teacher, or a teacher). Auto Generate never fills it.
  10. Summer / Winter timing: Periods & Breaks → choose Summer or Winter and set its times (⏱️ Auto timing works for each). Tick “Switch automatically by date” and set the winter dates – the app changes timing by itself.
  11. Timetable screen: switch Class / Teacher / Room and Week / Day; use Today ‹ › to see substitutions of any date in orange. Publish when ready.
  12. Drag & drop: in Timetable (Class) or Master Routine, drag a period onto another to swap (phone: press and hold, then drag). Green cells are safe; red would make a clash.
  13. Rooms: add labs in Setup → Rooms and give subjects a room in Allocation. See Room Time Table. Teacher Workload shows daily and weekly periods plus substitutions. Print Centre prints class-, teacher- and room-wise.
  14. Every morning use Absence Adjustment: tap the absent teachers – substitutes are chosen and saved automatically (fairest load first). Change any one by hand; it is marked ✋ and kept. Then send to the staff WhatsApp group.
  15. Print from any view (A4 landscape). Keep a Backup file often – data is saved in this browser only.
Morning and Noon shift periods are treated as different times, so one teacher can teach in both shifts. A teacher can never be put in two classes in the same period of the same shift.
